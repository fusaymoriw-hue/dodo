01 / START

ゲームの始め方

あなたは女子プロレス団体の経営者です。新人の発掘、入団交渉、練習指示、対戦カードの編成、興行結果の収支までを管理します。最初の6名を集めることが、旗揚げへの第一目標です。

OFFICIAL NEW GAME

正式ニューゲーム

所属0人から開始。時代・団体名・本拠地を決めて、新人テストやスカウトで仲間を集めます。初期資金は 1,000万円、開始は 1年目4月です。

OTHER MODES

試合・開発テスト・続きから

仮の6人を使う開発テスト、経営不要のお試し3D試合、保存した団体の続きを選べます。正式な創設1期生の記録とは区別されます。

新団体を始める手順

  1. タイトル画面で「0人から始める」を選択。
  2. 時代を選び、団体名と本拠地（東京・大阪・名古屋・福岡・札幌・仙台・広島・地方都市など）を設定。
  3. 最初は事務所に選手がいません。「選手を探す」から新人を発掘。
  4. 候補を見つけたら採用・契約交渉を行い、所属6人を目指します。
  5. 6人になったら「興行編成」で会場とカードを組み、旗揚げ興行へ。
補足：本拠地によって事務所・ジムの固定費、集客補正が変わります。団体名と本拠地は設立時によく確認してください。現在の開発版では、設立後に自由に変更する操作は通常画面に表示されません。

02 / GAME LOOP

1か月の進め方

ゲームは月単位で進みます。選手の行動や団体の方針を決めてから、月末処理で翌月へ進みます。

① 選手を探す・契約する

新人テスト（月1回）とスカウト遠征（月1回）を実施。交渉候補には有効期限があります。

② ジムで練習・休養

選手ごとに月間4枠のメニューを設定。必要ならその場で「いま練習する」を実行できます。

③ 興行・運営

所属6人以上なら月1回の自主興行を開催できます。スポンサー、広告、ファンサービスなども検討しましょう。

④ 月末処理

未実施の練習、出稼ぎ、給与・施設費・利息、各種収入、負傷回復、世界の出来事などを反映して翌月へ進みます。

注意：興行を開催しなくても、月末には給料や施設費が発生します。逆に、資金獲得を狙う出稼ぎのギャラは、その場ではなく月末に反映されます。

04 / SCOUT

スカウト・契約

「候補を発見する」ことと「入団させる」ことは別です。 新人テストの合格者は団体が採用を決定すると入団しますが、遠征で発見した選手は交渉が不成立になることもあります。

方法費用回数・特徴
新人テスト30万円月1回。所属が0人の場合は候補発見の救済あり。発見後、正式採用を決めます。
新人スカウト遠征25万円月1回の遠征枠を消費。国内6地区から新人を発掘。
フリー選手捜索30万円同じ遠征枠を使用。フリー選手の情報を探します。
他団体所属選手の調査35万円同じ遠征枠を使用。他団体選手の移籍・ゲスト参戦交渉の手掛かりを探します。

遠征先は「北海道・東北」「関東」「中部」「近畿」「中国・四国」「九州・沖縄」の6地区。見つからない場合も費用とその月の遠征枠は消費されます。

候補の有効期限と契約

  • 新人テスト／新人スカウトの候補は、発見した月と翌月まで保持。
  • フリー選手／移籍候補は、発見した月を含め3か月間保持。
  • 新人テスト合格者は、団体が採用を決定すれば辞退抽選なしで入団。探索費とは別に採用費が必要です。
  • 新人スカウト・フリー・移籍・ゲスト交渉は成功保証なし。失敗すると交渉費がかかり、交渉枠も消費します。
  • 通常の交渉枠は当初月2回。団体格が上がると増加します（新人テスト採用は別枠）。

オリジナル選手

名前・外見・得意系統などを決めて選手を作成する機能もあります。最初の1人を作る機能と、それ以後の発掘・タイトル画面のエディット選手は、条件や扱いがそれぞれ異なります。

初心者のコツ：所持金はすぐ減ります。探索費だけでなく採用費・月々の給料も見込んで、6人をそろえましょう。

05 / TRAINING

練習・疲労・選手との会話

練習メニューは選手1人につき1か月4枠。各枠に練習科目や休暇を設定します。「いま練習する」を使うと、月末を待たずに練習結果を確認できます。実施済みの練習を月末に重複計算しない仕組みです。

技：5系統

投げ／極め／パワー／打撃／飛び。能力値は原則1〜15で、経験を積むと成長します。

基礎：5能力

筋力／器用度／体力／回復力／速さ。試合や回復などに関わります。

休暇

1枠で疲労を22軽減します。練習の代わりに回復を優先できます。

技の特訓

通常の能力練習とは別に、技の習得・熟練を狙うメニューです。

疲労と回復

  • 通常の練習1枠で疲労+10。団体の志によって変動する場合があります。
  • 練習で疲労が72を超えた枠は成長しません。
  • 月末の回復は基本「20＋回復力」。設備などによる補正が加わります。
  • 試合後は試合の長さに応じて疲労が増えます。多日程興行ではコンディションを確認しましょう。

試合後の負傷リスク

試合前の疲労基本的な負傷判定率
50未満1%
50以上・70未満6%
70以上25%

上記は試合後の基本値です。団体の志や医療設備などの補正があります。練習枠ごとに同じ確率で負傷判定される、という意味ではありません。

モラル・会話・出稼ぎ

選手本人と3D会話ができ、イベントや声かけがモラル・絆などに影響することがあります。ジムでは練習の代わりに他団体への出稼ぎを選択できます。ギャラは月末に入金され、出稼ぎ中は自団体の興行や練習に参加できません。

06 / EVENT

興行と収支

所属選手が6人以上になると自主興行が解放されます。開催は月1回、その1回に1〜8日の日程を設定できます。

  1. 開催日数を1〜8日から選ぶ。
  2. 巡業（会場を回る）または集中興行（同会場中心）を選ぶ。
  3. 各日の会場を指定。会場には収容人数と使用料があり、団体格による利用制限があります。
  4. 対戦カードを作る。難しければ「全日程を自動仮編成」を利用。
  5. 自動決着／3D観戦／自分で操作する（赤側）を選び、開催する。
興行収支 ＝ 各日の（チケット売上 ＋ グッズ売上 − 会場費 − 移動・宿泊費）の合計

興行での観客数は、団体格・出場選手の人気・会場規模・開催形態・スポンサーや宣伝の影響などによって変化します。会場が大きければ必ず儲かるわけではありません。

AI社長の反省から：1日だけでなく8日間開催すれば、日ごとの収支を積み上げられます。ただし「1日目の黒字 × 8」が必ず成立するわけではありません。日程別の観客数やコストも確認しましょう。

王座戦（ジュニア／ヘビー級）の編成や記録にも対応しています。負傷中や出稼ぎ中の選手は、出場条件に注意してください。

資金の注意：興行の黒字は団体の最終的な月間黒字と同じではありません。月末には給料・事務所・ジム維持費・利息なども精算されます。

07 / BATTLE

3D試合と「五すくみ」

試合はReadRule01という5系統の読み合いルールに基づきます。技の数字・系統・選手の能力などで攻防を判定し、3D演出に反映します。

各系統の有利相性（実装準拠）

自分の技有利な相手イメージ
投げ飛び・極め飛びつきや関節技への入りを投げる
極めパワー・打撃突進や打撃を捕らえて関節を極める
パワー打撃・投げ強引に受け止め、力で押し切る
打撃投げ・飛び組みや飛び技を迎撃する
飛び極め・パワー空中から相手の動きに対応する

同じ系統同士には相性優位はつきません。各系統は2系統に強く、別の2系統に弱いルールです。

手札・守り・必殺技

  • 基本の手札は5枚。系統と数字を読み、使用可能な技を選びます。
  • 守りで相手の技系統を当てると、切り返しが成立する場合があります。
  • 闘志が満タンになると手札に必殺技カードが登場します。必殺技の切り返しには一定の闘志が必要です。
  • ダウン状態や技の難度などによって、選択できる技が変わります。
  • 3D試合には観戦・自分で操作・リプレイなどのモードがあります。

場外戦・反則・タッグ

  • 場外戦には20カウントの要素があり、トペ・スイシーダや場外ダイブなどが起きます。
  • ヒール選手の反則・凶器攻撃が発生する場合があります。反則負けにも注意。
  • タッグマッチでは交代・パートナーの介入・連携技・合体技などがあります。
実戦のコツ：相性だけで必ず勝てるわけではありません。札の強さ、能力、コンディション、切り返しなども結果に影響します。

08 / MANAGEMENT

運営・団体格・団体の志

「運営」画面では、興行以外の活動で団体を育てられます。多くのメニューは資金や回数制限があり、選手の人気・モラル・疲労・収益などに影響します。

🤝 スポンサー

条件に合う企業と契約し、月ごとの収入を得ます。

💝 ファンサービス

撮影会・サイン会・感謝デーなどで人気やモラルを伸ばします。

⛺ 合宿・♨️ 慰安旅行

合宿で成長、旅行で疲労・モラルを調整。月・年単位の利用制限があります。

📺 仕事・📣 広告・📰 情報発信

出演ギャラ、今月の興行集客、会報やファンクラブの活動などを管理。

🤜 国内提携・🌏 海外提携

他団体との交流戦、集客、海外修行の費用・育成補正に関わります。

🏗️ 設備・📝 契約更改

ジム・医療・グッズ設備などへの投資、毎年4月の給与交渉を行います。

団体格が上がると解放されるもの

団体格所属上限（基本）月間交渉枠会場上限
創設準備（0〜）10人2回800人
国内小規模（20〜）10人2回800人
国内中堅（60〜）12人3回1,500人
国内有力（120〜）14人3回3,000人
国内トップ（200〜）16人4回3,000人

設備による所属上限の増加など、個別の補正もあります。

団体の「志」

団体ごとの特殊な長所と短所を選ぶ仕組みです。たとえば「アイドル団体」は興行集客に強い代わりに練習に弱点があり、「鋼の肉体」は負傷しにくい方向に特化します。「志なし」で通常の団体として進めることもできます。

志の変更：一度選んだ志を別の志に変更する場合、基本的に300万円が必要です。長所だけでなく短所も読んで決めましょう。

そのほか、ライバル団体の動き、他団体からの引き抜き、団体・選手のエンディングなども運営画面から確認できます。

ワールドカップ（開発版で試合処理あり）

10 / DATA

記録とセーブ

ゲームはブラウザ内に進行状況を保存する仕組みを持ち、団体データをJSON形式で書き出すことができます。長く遊ぶときは、定期的な書き出しをおすすめします。

  1. 画面上部、または「記録・データ」画面から「セーブJSON出力」を選択。
  2. ダウンロードされたJSONを安全な場所に保管。
  3. 復元時は「セーブ読込」を選択して、対応する保存データを指定。
  4. 興行計画JSONや、所属・育成差分の書き出しは団体セーブとは別の用途です。
重要：古い版や別バージョンの保存データとの完全互換は保証されません。読み込み前には必ず現在のセーブを別途書き出し、バックアップを取ってください。

「記録・データ」では月別収支、選手・団体の出来事、過去の興行結果なども確認できます。

11 / TIPS

序盤の攻略とよくある質問

最初は何を目標にすればいい？

まず6人をそろえることです。新人テスト、スカウト、オリジナル選手などを使い、旗揚げ興行の解放を目指します。ただし採用費と翌月以降の給料も計算しておきましょう。

新人テストをしたのに入団しません

発見と採用は別操作です。候補一覧から正式に採用を決めてください。所属0人のときは候補発見に救済がありますが、以後は候補が見つからない月もあります。

練習をしたのに能力が伸びません

一度の練習で必ず能力値が1上がるわけではありません。経験が蓄積して成長します。疲労が72を超えた枠は成長しないので、休暇を挟むのも有効です。

出稼ぎの収入が増えません

出稼ぎのギャラは月末処理時に反映されます。出稼ぎを選んだ直後の資金表示だけで判断しないでください。

初興行で利益を出すには？

選手の人気と団体格に見合う会場を選び、会場費を抑えましょう。1〜8日開催を比較し、各日の日程を自動編成で埋める方法もあります。興行黒字でも月末の固定費で赤字になる場合があります。

バトルで相性を覚えるには？

「投げ → 飛び・極め」「極め → パワー・打撃」「パワー → 打撃・投げ」「打撃 → 投げ・飛び」「飛び → 極め・パワー」を覚えましょう。相手の系統を読んで守ることも重要です。

公開体験版とマニュアルが違うのはなぜ？

本マニュアルは2026年11月3日の現行開発版に対応しています。公開体験版は別バージョンで、開放されている機能や進行範囲が異なります。
