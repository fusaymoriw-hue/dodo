🎬 実況収録ツール

ゲーム画面を録画 → 考えている間を自動で詰める → カオルのメモの時刻を合わせる → 動画を書き出す（すべてこのパソコンの中だけで動きます）
使い方（はじめての方へ）
  1. このファイルを Chrome か Edge で開きます（ダブルクリック）。カオルが遊ぶゲームは、Claudeアプリの内蔵ブラウザで開いておきます（「⤢」で大きくしておくと見やすい）。
  2. 「🖥 撮る画面を選ぶ」を押します。内蔵ブラウザは「Chrome タブ」には出てきません。「ウィンドウ」でClaudeアプリを選ぶか、ゲームの音も録るなら「画面全体」＋「システムの音声も共有」をオンにします。
  3. 初回だけ：「✂ 録る範囲を囲む」でプレビューのゲームの所を囲みます。範囲は覚えておくので、次からは自動で使われます。
  4. 「● 録画開始」を押して、カオルに「録画開始しました」と送ります。カオルには、思ったことを時刻つきのメモ（例：22:31:05 うわ、連鎖した！）で残してもらいます。
  5. 終わったら「■ 録画停止」。囲んだ範囲だけの動画が、自動でダウンロードのフォルダに保存されます。
  6. その動画とカオルのメモを、対策室のチャットに渡せば、声と字幕を重ねた動画にします。

②〜④（間を詰める・メモの時刻合わせ・書き出し）は、必要なときだけ使う道具です。ふだんは使わなくてかまいません。別の道具で録った動画も「録った動画を読みこむ」から使えます。

2考えている間を詰める

「カット後を見る」は、カットする所を飛ばしながら再生します。テンポが速すぎたら「止まった所に残す長さ」を増やし、まだ間延びしていたら「何秒以上止まったら詰めるか」を減らします。

      

        
      

      
カット表は、Claudeの作業場で動画を仕上げるときに使います。

    

  







  
3カオルのメモ（時刻合わせ）

  
カオルのメモを貼りつけます。1行に1つ、行の先頭に時刻（22:31 か 22:31:05、[22:31:05] でも可）。カット後の動画の何秒目にあたるかを出します。

  

    
  

  
  

    ずれを直す（カチンコ合わせ）
    
カオルはできごとのあと少し遅れてメモを書くので、数秒ずれることがあります。表の行をクリックして選び、上の動画をその場面（たとえば連鎖した瞬間）に合わせて止めてから「この場面に合わせる」を押すと、全部の行がまとめてずれ直ります。
