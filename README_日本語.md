# 読み合いリング Ver.04_Rebuild02

## 起動

まず起動用ZIPを展開し、`Yomiai_Ver04_Rebuild02.html` を通常のChromeまたはEdgeで開いてください。単独HTML内に必要なコード・モデル・テクスチャ・名簿を含んでいます。外部URL、CDN、サーバーへの接続は必要ありません。Driveのプレビュー画面ではなく、保存したHTMLをブラウザーで開きます。

ソース一式のZIPでは、フォルダー全体を展開して `Yomiai_Ver04_Rebuild02/index.html` を開いてください。`src` フォルダーは移動しないでください。素材は `src/assets.js` にも内包されています。Pythonがある開発環境では `python build.py` で単独HTMLを再生成できます。遊ぶだけならPythonは不要です。

Rebuild01は別に残してください。Rebuild02は旧HTML・旧保存領域を上書きしません。

## 今回変えたこと

PCでは上に選手名・HP・試合時間、左に3D試合、右にカード・技・能力比較・ログを配置しました。試合開始後は選手設定を隠し、主要操作を一画面にまとめています。ブラウザーの表示倍率を100%に戻して確認してください。

狭い画面では、上に3D、下にカード・技を配置し、能力比較とログは「能力・ログ」ボタンで開きます。PC相当4サイズとスマホ縦2サイズで主要部品の画面内配置を検査していますが、これはChromiumの画面サイズを変更した検証であり、Android端末の実機検証ではありません。

既存GLBの骨格を使い、踏み込み、接触、投げ・打撃、受け身、着地、フォール、キックアウト、横向き、上体起こし、片膝、立ち上がり、構えへの復帰を連続した演出にしました。決着時はフォール姿勢を維持し、結果画面の背後で急に立ち姿へ戻る処理をやめています。

これらは独自のキーフレーム補間と骨格の接触補正です。物理シミュレーションでも原作モーションの完全再現でもありません。手や身体の重なり、足の滑り、髪・衣装の貫通など、見た目の調整は残っています。

## 一試合の操作

赤・青の選手を選び、「この2人で試合を始める」を押します。赤は手動、青はCPUです。

手札を1枚選ぶ → 同じ系統の技を選ぶ → 「この技で勝負」で確定、という順序です。カードを選んだだけではターンは進みません。「選び直す」でカード選択へ戻れます。

「成功したらフォールを狙う」は、赤側が攻撃権を取れた場合の指示です。青側はCPUがフォール指示を決めます。演出が終わり、構えに復帰すると次の手札を操作できます。

「全自動観戦」でも同じ試合計算を使います。演出速度は0.5倍、標準、2倍、4倍。一時停止中は演出時刻・ターンを進めません。試合記録や仕様画面へ移動した進行中の試合は一時停止されるので、戻ったら「再開」を押してください。

「直前の技」は、直前の攻防をもう一度表示します。新しい判定、HP減算、ターン追加、記録の追加保存はしません。自動観戦中に使った場合は再生終了後に自動進行へ戻ります。カメラはドラッグで回転、ホイールで距離調整。「視点を戻す」でリセットします。「撮影」は3D画面だけのPNG保存です。

1～5キーでも手札を選択できます。Spaceキーは一時停止／再開です。入力欄や選択欄にフォーカスがあるときはショートカットを使いません。

決着後は結果画面から再戦または選手変更へ進みます。途中中止は結果として保存しません。途中の試合の中断セーブは未実装です。

## 試合記録と旧JSON

Rebuild02の保存キーは `yomiai.Ver04_Rebuild02.results.v1`、最新100件です。Rebuild01の保存キーや経営セーブは読み書きしません。

「試合記録」の「結果JSONを読み込む」でRebuild01／Rebuild02のJSONを取り込めます。同じIDは重複登録せず、既に保存されている同IDの記録を優先します。別ファイル・別端末・別ブラウザーに移す前にはJSONを書き出してください。

ユーザー提供の `Yomiai_Rebuild01_results.json`（強力ゆうこ対雷鳴たつこ、9ターン）を同梱しています。「提供済みの旧記録を取り込む（1件）」を押すと明示的に併合できます。起動しただけでは自動登録しません。記録内の旧バージョン表示や勝敗は書き換えません。

保存に失敗した場合は結果画面で通知します。「結果保存を再試行」または「試合記録」からのJSON書き出しを使ってください。保存できなかった直近の結果も書き出し対象に含めます。

**本制作環境ではブラウザー標準の永続保存が拒否されました。保存の成功テストは、テストコードだけに挿入したメモリー保存器で実施しています。Windows／AndroidでHTMLを開き、ブラウザーを閉じてからも記録が残ることは未検証です。ゲーム本体には検証用保存器を入れていません。**

## 仕様と範囲

攻防、ダメージ、フォール確率、カードの配布・補充はRebuild01の独自暫定ルールを維持しました。原作の確定式だとは扱っていません。提供された9ターンは計算結果が一致しています。名簿の防御値欠落を攻撃値で代用する制限も継続しています。

シングルマッチ、打撃・投げ・パワー・その他のカード、試作技5種類が対象です。極め・飛び・必殺・合体は未対応です。経営・育成・興行・タッグ・リーグは最終目標の接続対象として残しており、本版で遊べる機能ではありません。

135人の名簿と既存素体・6種類の髪型を保持しています。道着未対応で選べない2人など、旧版の外見上の制限は継続です。既存GLBにアニメーションクリップはなく、本版の動作は骨格から作成しました。身体の代わりに球や棒の人形を表示する処理はありません。

## 検証の読み方

`docs/検証結果と未完了事項.md` に検証方法・合格項目・未検証項目を記載しています。画面写真、通し試合のJSON、判定回帰、配置検査、動作サンプル検査は `verification`、再実行用コードは `tests` にあります。

この制作環境ではローカルファイルへの直接ナビゲーションが管理ポリシーで拒否されます。配布HTMLそのものをChromiumの文書として読み込んで操作しました。描画は同じ実GLB・骨格・テクスチャを使うCPU経路で確認しています。GPU経路、Windowsダブルクリック、Android、全選手組合せの検収は未実施です。端末のセキュリティ設定を変更する必要はありません。
